# 데이터 · 도표

이 스킬은 **이미지 생성 모델을 쓰지 않는다.** 도표는 데이터에서 직접 그린다(SVG/HTML 표). 사진은
사용자가 제공한 실제 파일만 넣는다.

## 1. 도표 선택 기준

| 보여줄 것 | 고를 것 | 쓰지 말 것 |
|---|---|---|
| 단일 성과 수치 1–3개 | `kpi` (큰 숫자) | 원형 그래프 |
| 항목 간 크기 비교 | `bar` (가로 막대, 항목 ≤ 8) | 3D 막대 |
| 시간에 따른 변화 | `line` (점 ≤ 12) | 면적 그래프 남용 |
| 구성 비율 (2–4개) | 누적 막대 또는 `table` | 원형 그래프(5개 이상이면 특히) |
| 여러 항목 × 여러 지표 | `table` | 방사형 차트 |
| 프로세스 | `flow` (상자+화살표) | 그림 아이콘 나열 |
| 일정 | `timeline` | 간트 축소판 |
| 전후 비교 | `compare` (2열) | 이중 축 그래프 |

규칙:

- **한 슬라이드에 도표 1개.** 두 개가 필요하면 슬라이드를 나눈다.
- 축·단위·기간을 도표 안에 쓴다. 축 라벨 없는 그래프는 정보가 아니다.
- 출처는 도표 하단 각주에 `출처: 기관, 연도` 형식으로.
- 색은 악센트 1색 + 무채색. 항목이 많아도 무지개색 금지.
- 강조는 **한 항목만** 악센트로 칠하고 나머지는 회색.

## 2. 숫자 표기

| 상황 | 표기 | 예 |
|---|---|---|
| 비율 | 소수 첫째 자리 + % | 41.2% |
| 변화 | 부호 + 기준 | 21일 → 4일 (-81%) |
| 신뢰구간 | 괄호 + CI | 12.3% (95% CI 9.1–16.4) |
| 금액 | 천 단위 + 단위 | 1,840만원 / ₩18.4M |
| 기간 | 단위 명시 | 3개월(2026.07–09) |
| 큰 수 | 만/억 (한국식) | 12만 3천 건 |
| p값 | 소수 셋째 자리 | p = 0.012 |

- 단위를 슬라이드마다 통일한다(어떤 슬라이드는 만원, 어떤 슬라이드는 원 → 혼란).
- 반올림 규칙을 정하고 유지한다. 표와 본문의 숫자가 다르면 신뢰가 깨진다.
- 추정치는 "추정"이라고 쓰고 가정을 각주에 남긴다.

## 3. deck.json 에서의 표현

```json
{
  "type": "figure",
  "kicker": "결과",
  "title": "문진 자동화 후 대기가 21일에서 4일로 줄었습니다",
  "figure": {
    "kind": "bar",
    "data": [
      { "label": "도입 전", "value": 21 },
      { "label": "3개월 후", "value": 4 }
    ],
    "unit": "일",
    "emphasis": 1,
    "source": "출처: ○○병원 검진센터 운영기록, 2026.07–09"
  },
  "notes": "막대 두 개만 보여주고, 감소율은 말로 설명한다."
}
```

지원 `kind`: `kpi`, `bar`, `line`, `table`, `quote`, `compare`, `timeline`, `flow`, `none`.
`table` 은 `data` 를 `{ headers: [...], rows: [[...]] }` 로, `compare` 는
`{ left: {title, items[]}, right: {title, items[]} }` 로 받는다.

## 4. 도표를 그릴 때의 미학 (AI 티 방지)

- 격자선은 가로만, 아주 옅게. 세로 격자선은 기본적으로 넣지 않는다.
- 막대는 각지게(반경 0–2px). 둥근 막대는 AI 생성 그래프의 지문이다.
- 값 라벨은 막대 끝에 직접. 범례를 따로 두지 않는다(항목이 2개 이하면 직접 라벨).
- 축 눈금은 3–5개. 0부터 시작한다(막대 그래프).
- 배경은 슬라이드 배경과 같게 — 도표 상자에 회색 배경을 깔지 않는다.
- 그림자·그라디언트 채우기 금지.

## 5. 사진을 쓸 때

- 사용자가 준 실제 사진만. 파일명을 내용으로 바꾸고 출처를 각주에 적는다.
- 크롭은 `object-fit: cover` + 명시적 종횡비. 인물 사진은 얼굴이 잘리지 않게.
- 여러 장을 나열할 때는 같은 종횡비·같은 크롭으로.
- 저작권: 외부 이미지의 사용 허락을 확인하고, 불확실하면 쓰지 않는다.

## 6. 검증

- 도표마다: 축·단위·기간·출처가 있는가? 0 기준선인가? 강조가 1개인가?
- 본문 숫자와 도표 숫자가 일치하는가? (불일치는 치명적)
- 흑백으로 인쇄해도 읽히는가? (색만으로 구분하지 않았는가)
- `deck-check.sh` 로 슬라이드별 텍스트 밀도·폰트 최소치를 확인한다.
