# 덱 아키텍처 — 아웃라인, 유형, 시간

## 1. 아웃라인은 제목만 쓴다

발표의 골격은 **주장 문장의 목록**이다. 슬라이드 본문을 쓰기 전에 제목만 20줄 만든다.

```
✗ 나쁜 아웃라인            ✓ 좋은 아웃라인
1. 서론                    1. 위내시경 대기는 평균 21일입니다
2. 현황                    2. 대기의 41%는 사전 문진 누락에서 발생합니다
3. 방법                    3. 문진 자동화로 3개월 만에 21일 → 4일
4. 결과                    4. 같은 기간 검진 완료율은 12%p 올랐습니다
5. 결론                    5. 남은 병목은 내시경실 1개입니다 — 다음 분기 과제
```

규칙:

- 제목만 읽어도 **논증이 성립**해야 한다. 제목을 이어 붙여 요약문이 된다.
- 제목은 문장(주장)이고, 가능하면 동사로 끝난다. "현황", "개요", "방법" 같은 라벨 금지.
- 목차 슬라이드는 **주장을 붙인 목차**여야 한다(라벨만 나열하면 정보가 없다).
- 아웃라인 단계에서 사용자 승인을 받는다. 여기서 방향을 바꾸면 비용이 가장 싸다.

## 2. 장수 = 시간

| 발표 시간 | 슬라이드 | 비고 |
|---|---|---|
| 5분 | 6–8 | 문제 → 근거 1개 → 결론 |
| 10분 | 10–14 | + 방법·제한 |
| 15분 | 16–22 | 학회 일반 발표 |
| 20분 | 22–28 | 사례 2–3개 |
| 30분 | 30–40 | 워크숍·강의(중간 확인 문제 포함) |
| 45분+ | 40–60 | 강의: 15분마다 요약 슬라이드 |

계산: **슬라이드당 30–45초**. 도표·사례 슬라이드는 60–90초를 잡는다. 도입 인사 30초, 결론·감사
30초, Q&A 는 별도. 리허설이 목표의 ±10% 를 벗어나면 슬라이드를 자르거나 늘린다.

## 3. 슬라이드 유형 13종

각 슬라이드는 아래 중 하나의 `type` 을 갖는다. 유형이 곧 레이아웃이므로 **유형을 섞어 리듬**을 만든다.

| type | 쓰는 때 | 필수 요소 | 주의 |
|---|---|---|---|
| `cover` | 첫 장 | 제목, 부제(한 줄), 발표자·소속, 행사명·날짜 | 로고 남용 금지, 이메일·연락처는 마지막 장에 |
| `agenda` | 15분 이상 | 각 항목에 **결론**을 붙인 목차 | "개요" 라벨만 나열 금지 |
| `claim` | 논증의 각 단계 | 주장 1문장 + 근거 3개 이하 | 불릿 4개 초과 금지 |
| `evidence` | 데이터 제시 | 도표 + 해석 한 줄 + 출처 | 도표 1개, 축·단위 필수 |
| `figure` | 도표가 주인공 | 큰 도표 + 캡션 | 배경에 여백을 남긴다 |
| `compare` | 대안·전후 | 2열(또는 3열) + 판정 | 비교 기준을 명시 |
| `quote` | 권위·맥락 | 인용문 + 출처·연도 | 20단어 이내, 임의 각색 금지 |
| `timeline` | 일정·경과 | 3–5단계 + 각 시점 | 마일스톤에 날짜를 쓴다 |
| `kpi` | 성과 1–3개 | 숫자 + 라벨 + 기준 시점 | 숫자 크기 최우선 |
| `flow` | 프로세스 | 3–5 상자 + 화살표 | 각 상자에 산출물 |
| `team` | 사람 | 이름·역할 | 사진은 실제 사진만 |
| `closing` | 결론 | 요청/결론 1문장 + 다음 단계 | "감사합니다"로 끝내지 않는다 |
| `appendix` | 백업 | 상세 표·방법·참고문헌 | 발표 중엔 건너뛴다(Q&A용) |

밀도 모드(발표용/배포용)는 `meta.mode` 로 정한다.

- `present`: 한 슬라이드 한 아이디어, 불릿 3–4개, 폰트 크게. 발표장 뒤에서 읽힌다.
- `leave-behind`: 읽어도 이해되는 조밀한 버전(문장형 불릿, 각주 포함). 같은 아웃라인에서
  `body` 를 늘려 만든다.

## 4. 리듬 만들기

- 같은 유형 3연속 금지. `claim → evidence → claim` 이 기본 박자.
- 5–7장마다 `section` 표지(큰 글씨, 한 줄)로 숨을 쉬게 한다.
- 도표 슬라이드 뒤에는 **해석 한 줄**만 있는 슬라이드를 두면 메시지가 남는다.
- 마지막 2장은 `closing` + `appendix`. Q&A 대비 표는 부록에.

## 5. 쓸모없는 슬라이드 (삭제 대상)

| 패턴 | 이유 | 대안 |
|---|---|---|
| 목차 라벨만 나열 | 정보 없음 | 각 항목에 결론 붙이기 |
| 자기소개 3장 | 시간 낭비 | 표지에 소속·직함 1줄 |
| "감사합니다"만 있는 마지막 장 | 요청이 사라짐 | 결론·요청·연락처 |
| 회사 연혁 타임라인 | 청중 무관 | 지금 성과만 |
| 목적/비전 슬로건만 | 검증 불가 | 수치·사례 |
| 백업 없이 세부 통계를 본편에 | 시간 초과 | 부록으로 이동 |
