# 스피커 노트 · Q&A · 리허설

## 1. 노트는 "읽는 대본"이 아니다

슬라이드에 없는 것을 말하고, 슬라이드에 있는 것은 말하지 않는다. `make-deck.py` 가 만드는
`speaker.md` 를 아래 형식으로 채운다.

```markdown
## 05 — 문진 자동화로 21일 → 4일
**목표 시간** 45초  ·  **누적** 3:20 / 15:00
**핵심 한 문장** 대기의 41%는 문진 누락에서 발생했고, 자동화로 그 부분을 없앴습니다.
**말할 것**
- 도입 전 21일 중 8.6일이 문진 재확인 대기였다
- 3개월 운영 후 4일, 완료율 12%p 상승
**하지 말 것** 표의 모든 숫자를 읽지 않는다. 두 막대만 가리킨다.
**전환 문장** "그럼 남은 병목은 어디일까요?"
**예상 질문** 표본이 3개월뿐인데 계절성은? → 부록 12
```

- **핵심 한 문장**을 먼저 정한다. 이것을 못 쓰면 슬라이드가 필요 없다.
- 말할 것은 3줄 이내. 슬라이드 텍스트를 복사하지 않는다.
- 전환 문장을 반드시 쓴다. 슬라이드 사이가 끊기면 청중이 이탈한다.
- 목표 시간을 적고 리허설에서 실측한다.

## 2. 시간 배분 (15분 발표 예시)

| 구간 | 시간 | 슬라이드 |
|---|---|---|
| 도입·인사·결론 예고 | 0:40 | cover + claim |
| 배경·문제 | 2:30 | 3–4장 |
| 방법 | 2:00 | 2–3장 |
| 결과 | 5:00 | 4–6장 (도표 중심) |
| 한계·비교 | 1:30 | 2장 |
| 결론·요청 | 1:20 | 1–2장 |
| 여유 | 2:00 | 예상 초과분 |

- 15분 발표는 실제로 **13분**을 목표로 만든다(질문·장비 문제로 2분이 사라진다).
- 도표 슬라이드는 예상보다 1.5배 오래 걸린다.
- 시간 초과 시 자를 순서를 미리 정한다(보통 방법 세부 → 부록).

## 3. Q&A 대비

발표 전에 질문을 5–8개 예상하고 부록 슬라이드로 답을 준비한다.

| 예상 질문 유형 | 준비물 |
|---|---|
| 표본·방법 타당성 | 대상 선정 흐름도, 탈락률, 민감도 분석 |
| 수치 근거 | 산식·원자료 요약, 통계 연도 |
| 일반화 가능성 | 하위군 결과, 외부 타당도 논의 |
| 비용·자원 | 단가 산정, 인력·시간 투입 |
| 반대 사례 | 실패 사례와 원인, 대응 계획 |
| 다음 단계 | 로드맵, 담당, 지표 |

답변 형식: **결론 1문장 → 근거 1–2개 → 부록 번호**. 모르면 "지금은 데이터가 없습니다.
○일까지 확인해 공유하겠습니다" 라고 말한다 — 추측하지 않는다.

## 4. 리허설 체크

1. 타이머를 켜고 **실제로 소리 내어** 1회 완주한다. 목표 ±10% 확인.
2. 기기를 바꿔 본다(발표 PC 해상도·폰트·발표자 노트 창).
3. 첫 30초와 마지막 30초를 외운다(가장 실수가 많은 구간).
4. 도표를 가리키는 동작을 정한다(마우스 커서 위치·레이저).
5. 슬라이드 넘김 리듬을 정한다(문장 끝에서 넘긴다).
6. 질문 3개를 동료에게 받아본다.

## 5. 내보내기 체크

| 형식 | 언제 | 확인 |
|---|---|---|
| `deck.html` | 발표 화면 | ←/→ 이동, `f` 전체화면, `n` 발표자 노트, 폰트 로딩 |
| PNG | 메신저·SNS 공유, 인쇄 | 1920×1080, 텍스트 선명도 |
| PDF | 배포·이메일, 발표장 PC 가 다를 때 | 16:9 페이지, 폰트 임베드, 클릭 링크 |
| PPTX | 주최측이 편집을 요구할 때 | 텍스트 편집 가능, 노트 포함, 도표는 이미지 |

- 발표장 PC 가 확실하지 않으면 **PDF 로 발표**한다(폰트 대체 사고 방지).
- PDF 는 인쇄용이 아니면 페이지 여백 0, 배경 포함 옵션을 확인한다.
- PPTX 는 16:9(13.333in × 7.5in)이고, 열었을 때 폰트가 없으면 대체된다 — 주최측에 폰트를 알려준다.

## 6. 발표 당일

- 파일 3중 백업: 노트북, USB, 클라우드 링크.
- 발표자 노트 창이 열리는지 실제로 확인(팝업 허용).
- 마이크·클리커 테스트, 슬라이드 번호로 이동하는 방법 확인.
- 첫 문장을 적어 손에 들고 시작한다.
