# Technical / Clinical / Policy Report Template

## 1. Summary (bottom line first)
- The question, the answer, and the confidence in one paragraph.

## 2. Context and scope
- Why this report exists; what it covers; what it excludes.

## 3. Question
- Main question and subquestions (and any PICO elements).

## 4. Methods
- Sources searched, queries, dates, inclusion/exclusion.
- Appraisal approach (only frameworks actually applied).
- Access limitations encountered.

## 5. Evidence
- Synthesized by theme (not paper-by-paper).
- Key evidence table: claim · source · design · population · effect (CI) · n ·
  support_status · limitations.

## 6. Options
- Option A/B/…: description, evidence strength, benefits, harms, resource use,
  applicability to the target population.

## 7. Recommendation
- Recommended option + **strength of recommendation** + the evidence it rests on.
- Explicit uncertainties and conditions under which it would change.

## 8. Implementation
- Steps, responsible roles, monitoring indicators, review date.

## 9. Limitations & gaps
- What the evidence cannot answer; items requiring human review.

## 10. References & appendices
- Verified bibliography; search/methods log; evidence ledger; AI-use statement.
