## 1. 표지 — 10초

안녕하십니까. 예시병원 가정의학과 김예시입니다.

이번 발표에서는 초음파에서 발견된 병변을 어떻게 나누어 볼지에 대한 탐색적 연구를 말씀드리겠습니다.

> 무대: 제목과 소속만 짚고 바로 넘어간다.

---

## 2. 배경 — 60초

먼저 배경입니다. 영상에서 발견된 병변을 감별할 때, 사람이 판독한 정확도는 문헌에서 **76.0%** 수준이었습니다.

- **정확도** — 전체 판정 중 맞춘 비율입니다.
- **민감도** — 병이 있는 사람을 병이 있다고 부른 비율입니다.
- **특이도** — 병이 없는 사람을 없다고 부른 비율입니다.

데이터는 공개 데이터셋 clean subset, **744명 2,656장**이고 — train 1,858 / val 530 / test 268 — **환자 단위**로 나눴습니다.

## 3. 방법 — 90초

방법입니다. 영상이 인코더를 지나 임베딩이 되고, 거기서 **세 개의 숫자**가 나옵니다.

1. Confidence — 지금까지 AI가 내던 softmax 값입니다.
2. HCC cosine — 전형 HCC와 얼마나 닮았는지입니다.
3. Δscore — 두 코사인의 차이입니다.

> 무대: 애니메이션이 이미지 → 인코더 → 임베딩으로 흐르는 것을 한 번 보여준다.

중요한 건 세 지표가 전부 임베딩 하나에서 나온다는 점입니다.

## 4. 마무리 — 20초

이상입니다. 오늘 말씀드린 것은 두 가지입니다. **닮음 점수라는 두 번째 숫자를 만들었다**는 것, 그리고 **그 숫자가 아직 임상적 이득을 입증하지 못했다**는 것.

질문과 토론을 환영합니다. 감사합니다.
