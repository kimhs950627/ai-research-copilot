# Argument pass — 논지 전개와 논증 건전성

Read this when doing Step 3, or when `claim_chain.py` reports `UNSUPPORTED` / `causal!`.
Adapted from `Natsummerance/skills` → `academic-argument-logic` (MIT, Grade A), whoseframe is
data→conclusion validity, alternative-hypothesis exclusion, and chain-break detection.

## 원칙

논증의 결함은 **문장 문제가 아니라 사고 문제**다. 문장을 다듬어도 "데이터가 결론을 지지하지
않음"은 고쳐지지 않는다. 그래서 이 패스는 수정 문장을 쓰지 않고, **주장과 근거를 분리해
나란히 놓고** 끊어진 곳을 지목한다.

두 가지 병이 대부분이다:

1. **데이터가 결론을 지지하지 않음** — 근거가 결론보다 약한데 어휘가 세다.
2. **논증 사슬의 결손** — 각 문장은 맞는데 연결이 없다. 독자가 채워야 할 전제가 빠져 있음.

## 검사 A — 데이터에서 결론으로 (4문항)

각 핵심 주장마다:

1. **뒤집기 검사** — 반대 자료를 넣어도 같은 결론이 나오는가? ("80%의 우등생이 낮잠을 잔다"는
   낮잠의 효과를 지지하지 않는다. 열등생 100%가 낮잠을 잔다면?) 나오면 근거가 아니다.
2. **동질성 검사** — 비교하는 두 군의 선택 과정이 같은가? (제왕절개 사망률이 높다는 것이
   제왕절개가 나쁘다는 뜻이 아닌 이유는 적응증 때문에 군이 이미 다르기 때문)
3. **대안 가설 검사** — 상관 결과라면 최소 3개를 적어본다: 제3변수, 역인과, 선택편향,
   생태학적 오류(국가 단위 자료로 개인 결론).
4. **단위 검사** — 분석 단위와 결론 단위가 같은가? 국가 수준 상관을 개인 행동으로 옮기면 오류.

## 검사 B — 사슬 끊김

1. 논증을 명제 열로 바꾼다: P1 → P2 → … → C. 초록 주장이 C다.
2. 이웃한 명제 사이마다 묻는다: **P(n)에서 P(n+1)로 가려면 무엇이 더 필요한가?** 정의인가,
   문헌인가, 아니면 데이터인가?
3. 인과 진술은 특히: "앞뒤가 다 맞는데 왜 이것이 저것을 **반드시** 일으키는가?"
4. 불일치 결과를 해명하는 문단이 **불일치를 해소하는지, 아니면 반대편에 재료를 주는지** 확인.
   "우리 결과가 X와 다르지만 측정 방법이 달랐기 때문"은 해소가 아니라 새 약점인 경우가 많다.

`claim_chain.py`는 1과 3의 어휘적 절반만 한다: 초록·결론의 결과 주장을 뽑아 Results 문장과
대응시키고, 인과 어휘가 설계 강도를 넘으면 HIGH로 올린다. **사슬 끊김은 자동화되지 않는다.**

## 검사 C — 대안 가설의 명시적 배제

관찰 연구의 설득력은 **배제한 대안의 수**에서 나온다. 논의에 다음이 있는지 본다:

- 교란·잔여 교란 (제3변수)
- 역인과
- 선택·생존 편향
- 측정 오류·분류 오류
- 단일 원인 귀속 (여러 변화가 동시에 일어난 기간의 추세 해석)

각각에 대해 **"만약 그 가설이 참이면 무엇이 관찰되어야 하는가 / 실제로 무엇이 관찰되었는가"**
형식으로 적혀 있어야 배제다. "고려하지 못했다"만 있으면 배제가 아니라 고백이다.
스크립트가 `대안 가설 언급 없음`을 MED로 올리면, 그건 문장이 아니라 문단을 추가하라는 뜻.

## 검사 D — 흔한 논리 결함 빠른표

| 결함 | 원고에서의 모습 | 판정 |
|---|---|---|
| 상관을 인과로 | "X가 증가하자 Y도 증가했다" | HIGH (설계가 관찰이면) |
| 표본 편향 | "설문 응답자 100%가 ~라고 답했다" | HIGH |
| 생존자 편향 | 남아 있는 사례만 분석 | HIGH |
| 단일 원인 귀속 | "유병률 증가는 X 때문" (동시대 변화 다수) | MED |
| 기준선 교란 | "옛사람은 암이 적었다" (수명 미고려) | MED |
| 생태학적 오류 | 지역 상관 → 개인 결론 | HIGH |
| 순환 정의 | 노출과 결과가 같은 측정에서 나옴 | HIGH (설계 문제) |
| 임의 절단 | 연속변수를 근거 없이 이분 | MED |

## 리포트에 쓰는 법

논증 지적은 **주장 문장을 그대로 인용**하고, 근거 위치를 대고, 끊긴 고리 하나만 지목한다.

```
[HIGH] paper.md L3 — "proves that early endoscopy reduces mortality"
근거: Results L18은 단변량 OR만 제시(L19에 조정 모형 없음).
끊긴 고리: 교란(중증도) 통제 → 없으면 관찰 연구에서 "reduces"는 성립하지 않음.
제안: 조정 모형 결과를 추가하거나 "was associated with lower mortality"로 내린다.
```

## 경계

- 형식 논리(삼단논법) 검증, 수학 증명, 통계 재계산은 범위 밖.
- 대안 가설은 무한히 만들 수 있다. **심사자가 실제로 제기할 것** 상위 3개로 제한한다.
  무한 의심은 리뷰가 아니라 회의주의다.
