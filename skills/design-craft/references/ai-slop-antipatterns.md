# AI 티 대조표 — 증상 → 진단 → 대안

"AI 티"는 스타일 취향 문제가 아니라 **기본값(default)으로 수렴하는 현상**이다. 모델은 학습 분포의
평균을 낸다. 아래 신호가 보이면 의도적으로 분포에서 벗어나야 한다.

등급: **HIGH** = 그 자체로 AI 생성물로 읽힌다. **MED** = 맥락 없이 쓰면 평범해진다.
**LOW** = 남용하면 단조로워진다. `scripts/design-lint.py` 가 HIGH/MED 를 자동 검출한다.

## 타이포

| 증상 | 등급 | 진단 |
|---|---|---|
| `Inter`, `Roboto`, `Arial`, `system-ui`, `-apple-system` | HIGH | 기본값. 폰트 선택을 안 했다는 뜻 |
| `Poppins`, `Montserrat`, `Lato`, `Open Sans` | MED | 2020년대 초 AI 생성물의 표준 |
| `Space Grotesk` | MED | 한때 유행해서 이제 생성물 지문이 됐다 |
| 제목/본문이 같은 폰트의 굵기 차이뿐 | MED | Display/body 페어가 없다 |
| 모든 크기가 16/18/24/32px 균등 | LOW | 모듈러 스케일이 없다 |
| 큰 제목 자간 0 | LOW | 큰 글자는 자간을 좁혀야(-0.02em) 조여 보인다 |

대안: 톤에 맞는 실제 폰트를 **고른다**. 세리프 디스플레이 + 산세리프 본문, 또는 지오메트릭 +
그로테스크. 한글은 Pretendard 하나로 통일하지 말고 제목용/본문용을 나누거나, 최소한 무게·자간을
의도적으로 설계한다.

## 색

| 증상 | 등급 | 진단 |
|---|---|---|
| 보라·인디고 그라디언트 (`#8b5cf6`, `#6366f1`, `#a855f7`, `#7c3aed`, `#4f46e5`) | HIGH | AI 생성 랜딩페이지의 대표 지문 |
| `#000` 배경 + `#fff` 텍스트 | MED | 순수 흑백. 웜톤/쿨톤 검정이 질감을 만든다 |
| 5색 이상 균등 배분 팔레트 | MED | 지배색이 없다 = 결정을 안 했다 |
| 악센트가 페이지 곳곳에 흩어짐 | LOW | 악센트는 한 곳에서 강하게 |
| `linear-gradient` 를 버튼마다 | LOW | 그라디언트는 배경 재질에 쓰는 도구다 |

대안: 배경·텍스트·악센트·상태 4계열만 토큰으로. 순수 검정 대신 `#141210`~`#1A1714`, 순수 흰색 대신
`#FBFAF8` 같은 의도적 오프값. 악센트는 한 색으로 밀고 나머지는 무채색.

## 레이아웃

| 증상 | 등급 | 진단 |
|---|---|---|
| 가운데 정렬 히어로 → 3개 기능 카드 → CTA → 푸터 | HIGH | 템플릿 문법. 내용이 레이아웃을 결정하지 않았다 |
| 동일 크기 카드 3~4개가 균등 간격 | HIGH | 리듬이 없다. Bento/비대칭/크기 차등 필요 |
| 모든 섹션이 같은 컨테이너 폭·같은 상하 여백 | MED | 섹션별 밀도 변화가 없다 |
| 대칭 좌우 2단 반복 | MED | Asymmetric split 또는 오버랩 |
| mean 간격이 전부 16/24px | LOW | 과감한 여백(120px+)이 없다 |
| 히어로 높이 `100vh` 고정 | LOW | 모바일 주소창 문제. `svh`/`dvh` 사용 |

대안: 섹션마다 **밀도를 바꾼다**(꽉 찬 섹션 → 텅 빈 섹션). 그리드를 한 번은 깬다. 히어로 다음에
바로 그리드로 넘어가면 스토리텔링이 끊긴다 — 브랜드 메시지/무드 브릿지 섹션을 넣는다.

## 표면 · 효과

| 증상 | 등급 | 진단 |
|---|---|---|
| 모든 카드 `border-radius: 8px` + `box-shadow` | HIGH | 기본 컴포넌트 문법 |
| `glassmorphism` (blur+border+투명도) 남용 | MED | 2021년 유행 지문 |
| 이모지로 아이콘 대체 (🚀 ✨ 🔥) | MED | 아이콘 세트를 정하거나 아예 뺀다 |
| `transition: all .3s` | MED | 무엇이 변하는지 정의하지 않음 |
| 배경이 단색뿐 | MED | 그레인·메시·텍스처로 깊이를 준다 |
| 모든 hover 가 `scale(1.05)` | LOW | 눌림/이동/색 변화를 섞는다 |
| 무의미한 blob/SVG 장식 | LOW | 장식은 구조를 설명할 때만 |

대안: 반경을 토큰에 2~3단계만 두고(예: 2px/6px/999px) 카드에는 그림자 대신 1px 보더 +
배경 대비로 층을 만든다. 클릭 요소 hover 는 이동·색·보더 중 하나로 통일한다.

## 카피

| 증상 | 등급 | 진단 |
|---|---|---|
| "혁신적인 솔루션", "seamless", "empower your workflow" | HIGH | 내용이 없는 마케팅 평균문 |
| Lorem ipsum 잔존 | HIGH | 미완성 |
| 기능 나열만 있고 결과/수치가 없음 | MED | "빠른 동기화" → "3초 안에 전체 동기화" |
| 모든 버튼이 "시작하기" | LOW | 문맥별 동사 + 목적어 |

대안: 카피를 **데이터 계층**에 쓰고, 구체적 사실·수치·제품명을 넣는다. 문장 길이를 섞는다
(짧은 단언 + 긴 설명).

## 접근성 · 완성도 (AI 티보다 더 치명적)

| 증상 | 등급 | 진단 |
|---|---|---|
| `:focus` 스타일 없음 / `outline: none` | HIGH | 키보드 사용 불가 |
| 본문 대비 4.5:1 미만 | HIGH | WCAG AA 위반 |
| `prefers-reduced-motion` 분기 없음 | MED | 모션 민감 사용자 배려 없음 |
| `img` 에 `alt` 없음 | MED | 스크린리더 |
| 텍스트가 컴포넌트에 하드코딩 | MED | 유지보수 붕괴 (데이터/UI 분리 위반) |
| 색/간격 hex·px 가 코드 곳곳에 | MED | 토큰 아님 |
| 375px 에서 가로 스크롤 발생 | HIGH | 반응형 미완 |

## 자기 점검 6문항

1. 이 화면에서 **가장 기억에 남는 한 가지**는 무엇인가? 답이 없으면 다시 설계한다.
2. 폰트를 왜 골랐는지 한 문장으로 설명할 수 있는가?
3. 섹션별 밀도가 실제로 다른가? (전부 비슷하면 실패)
4. 색 결정이 토큰 한 곳에 있는가?
5. 카피에 구체적 사실/수치가 있는가?
6. 화면을 흑백으로 바꿔도 위계가 읽히는가?
