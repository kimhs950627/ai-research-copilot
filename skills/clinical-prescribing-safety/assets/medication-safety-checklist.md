# Medication Safety Checklist

Run before finalizing any plan. Record the result of every line.

## Patient parameters
- [ ] Age / sex
- [ ] Weight (kg) — and BSA if relevant
- [ ] Pregnancy / lactation status
- [ ] Renal function (eGFR or CrCl) — state method
- [ ] Hepatic function (Child–Pugh if relevant)
- [ ] Allergies / prior ADRs
- [ ] Comorbidities
- [ ] Full medication list (incl. OTC, herbal, supplements)

## Indication & source
- [ ] Indication matches an approved/guideline-supported use
- [ ] First-line vs alternative justified
- [ ] Off-label use flagged with evidence
- [ ] Source cited (label/guideline)

## Safety screen
- [ ] Contraindications (absolute / relative) checked
- [ ] Allergy / cross-reactivity checked
- [ ] Drug–drug interactions checked (PK + PD)
- [ ] Duplication / therapeutic overlap checked
- [ ] Disease-state cautions checked
- [ ] Pregnancy/lactation risk checked
- [ ] Special-population issues checked

## Dose
- [ ] Route, formulation, strength
- [ ] Per dose and per day stated; max dose respected
- [ ] Weight/BSA basis stated if applicable
- [ ] Renal/hepatic adjustment applied
- [ ] Loading vs maintenance distinguished
- [ ] Arithmetic recomputed and shown
- [ ] Duration / taper / stop plan

## Monitoring
- [ ] Parameter(s) named
- [ ] Interval and target stated
- [ ] Action on abnormal result stated
- [ ] Efficacy reassessment date set

## Counselling
- [ ] Administration instructions
- [ ] Common side effects
- [ ] Serious warning signs (plain language)
- [ ] Interactions to avoid (food/alcohol/OTC)
- [ ] Missed-dose guidance

## Governance
- [ ] Uncertainties / gaps listed
- [ ] Human clinician review and approval line present
- [ ] AI-use disclosed where required
