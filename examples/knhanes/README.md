# KNHANES 연습 — 첫 표까지 30분

실제 분석을 하기 전에, **빈 표를 먼저 그리는** 연습입니다. 데이터가 없어도 됩니다.
목표는 “AI에게 무엇을 물어야 하는지”를 몸에 익히는 것입니다.

## 준비

1. 빈 폴더 `knhanes-practice`를 만들고 OpenCode로 연다.
2. 아래 프롬프트를 순서대로 보낸다.
3. 각 단계마다 AI가 만든 파일을 **직접 열어** 확인한다.

## 1단계 — 질문을 한 문장으로

```
@academic-research-writing
다음 아이디어를 PICO로 정리해줘. 설계 후보 2개와 장단점.
아직 원고는 쓰지 마.

아이디어: 국민건강영양조사에서 40세 이상 성인의
복부비만과 대사증후군 유병률이 연도별로 어떻게 변했는지 보고 싶다.
```

확인: PICO의 O(결과)가 “대사증후군”처럼 **측정 가능한 정의**로 바뀌었는가.

## 2단계 — 폴더 만들기

```
지금 폴더에 논문 한 편용 구조를 만들어줘.
raw는 읽기 전용, derived는 코드가 만들 것, notes/decision.md 포함.
파일은 만들지 말고 폴더와 README만. 먼저 목록을 보여줘.
```

## 3단계 — 빈 표 설계

```
표 1(대상 특성), 표 2(연도별 유병률), 표 3(로지스틱 회귀)의
빈 표를 만들어줘. 각 열의 정의와 단위를 캡션에 적어.
숫자는 아직 채우지 마.
```

확인: 표 2의 열이 “연도 / n(가중) / 유병률(95% CI)”로 되어 있는가.
“n”과 “가중 n”이 구분되어 있는가.

## 4단계 — 복합표본 체크리스트

```
이 분석에서 복합표본설계와 관련해 내가 확인해야 할 항목을
체크리스트로 만들어줘. 층·집락·가중치·연도 통합·결측.
각 항목에 "왜 중요한가"를 한 줄씩.
```

## 5단계 — 실패를 미리 상상하기

```
이 연구가 심사에서 받을 수 있는 비판 7개를 심각한 순서로.
각 비판에 "지금 준비할 수 있는 방어"와 "데이터로 방어 불가능한 부분"을 구분해.
```

## 통과 기준

- [ ] 연구 질문이 한 문장이다.
- [ ] 표 3개의 열 정의가 서로 맞는다.
- [ ] 가중치 변수 이름을 **코드북에서** 확인했다.
- [ ] 연도 통합 방식을 **추측하지 않고** 확인 대상으로 남겼다.
- [ ] 심사 비판 7개 중 3개에 대한 방어를 준비했다.

이 다섯 개가 되면 실제 데이터를 넣어도 순서가 무너지지 않습니다.
