## 한 장 요약

| 항목 | 내용 |
|---|---|
| 질문 | B-mode 초음파에서 HCC와 혈관종을 구분할 때, 단일 확률값 외에 “얼마나 HCC다운가”를 연속값으로 줄 수 있는가 |
| 데이터 | SMC-LUD 공개 데이터셋 · clean subset 2,656장 / 744명 · 환자 단위 분할 |
| 모델 | CNN–Transformer 하이브리드(EfficientNetV2B0 + transformer) · SupCon |
| 주 결과 | 테스트 268장 · 민감도 95.71% · 특이도 100% · 정확도 97.76% |
| 탐색적 지표 | 닮음 점수 140/1/0/127 (민감도 100 · 특이도 99.22 · 정확도 99.63) |
| 정직한 한계 | 불일치 6 vs 1, McNemar exact p = 0.125 → 우월성 주장 없음 |
| 발표 | 13장 · 8분 + 질의 2분 · 대본 7분 35초 · 큐카드 19장 |

## 이 사례에서 가져온 것

1. **컷오프는 점이 아니라 구간** — 검증에서 오류가 0이 되는 구간의 위쪽 끝.
2. **이기지 못하면 실패 지점을 말한다** — “차이는 유의하지 않다. 다만 실패하는 지점이 다르다.”
3. **한계 슬라이드를 먼저 만든다** — 질의에서 그 슬라이드로 돌아간다.
4. **IRB·계속 연구·임상 응용** 세 질문을 미리 준비한다.
