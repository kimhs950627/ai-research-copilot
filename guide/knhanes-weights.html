국민건강영양조사 가중치 — 2024(제9기 3차년도) 코드북을 읽고

한 줄 결론 — 2024년 원시자료에는 wt_exam이 없습니다. 건강설문+검진은 wt_itvex, 영양까지 함께 쓰면 wt_tot, 영양만 쓰면 wt_ntr 입니다. 층은 kstrata, 집락은 psu입니다.

근거: 질병관리청, 『국민건강영양조사 원시자료 이용지침서 제9기(2022-2024)』, 2025-12-30 공개, 2026-07 업데이트, 255쪽. 이 문서의 쪽수는 PDF 쪽수가 아니라 책에 인쇄된 쪽수입니다.

1. 2024년에 실제로 있는 가중치

지침서 p.94의 변수설명 표에서 확인한 이름입니다.

변수설명쓰는 경우
wt_hs가구조사 가중치가구 단위 분석(가구소득, 가구원수 등)
wt_itvex건강설문–검진조사 가중치건강면접·건강행태·검진 변수를 함께 쓰는 가장 흔한 분석
wt_ntr영양조사 가중치영양 변수만(연령·성별·연도 보정 포함)
wt_tot건강설문–검진 + 영양조사 가중치검진 변수와 영양 변수를 한 모형에
wt_oe구강검사 가중치구강검사만
wt_oent구강검사 + 영양조사구강 + 영양
wt_bia체성분검사 가중치(10세 이상)2022년만
wt_biant체성분 + 영양2022년만
wt_pft폐기능검사 가중치2024년만
wt_pfnt폐기능 + 영양2024년만

공통 설계 변수:

  • kstrata — 분산추정 층
  • psu — 1차 추출단위(조사구)
2024년에는 wt_ex, wt_exam, wt_itv, wt_bhv가 기본 가중치로 배포되지 않습니다. 2010년부터 건강설문·검진이 wt_itvex로 통합되었고, 2024년 코드북에도 그 이름만 있습니다.

2. 가중치는 “결과 변수”가 아니라 “함께 넣는 모든 변수”로 정한다

지침서 p.23–24의 원칙입니다. 회귀분석처럼 여러 변수를 동시에 넣으면, 그 모형에 들어가는 모든 분석변수의 조사 부문·영역·항목을 보고 가중치를 고릅니다. 결과 변수 하나만 보고 고르면 틀립니다.

지침서 p.28의 표 6-2를 2024년 기준으로 줄이면:

함께 분석하는 변수2024년 가중치
건강설문(면접/행태) + 검진wt_itvex
건강설문 + 영양wt_tot
검진 + 영양wt_tot
건강설문 + 검진 + 영양wt_tot
구강 + (건강설문 또는 검진)wt_oe
구강 + 영양wt_oent
체성분(2022만) + (건강설문 또는 검진)wt_bia
체성분(2022만) + 영양wt_biant
폐기능(2024만) + (건강설문 또는 검진)wt_pft
폐기능(2024만) + 영양wt_pfnt

자주 하는 선택

  • BMI(검진) + 고혈압(검진/설문) → wt_itvex
  • BMI + 에너지 섭취량(영양) → wt_tot
  • 에너지 섭취량 + 연령·성별 → wt_ntr (연령·성별은 모든 부문에 공통)
  • 가구소득 + 가구원수 → wt_hs
  • 구강검사 + 식이 → wt_oent
  • 폐기능(2024) + BMI → wt_pft
  • 폐기능(2024) + 식이 → wt_pfnt

3. 최소 분석 코드

R — survey

library(survey)

# 2024년 기본 DB: HNYR_ALL (YR=24)
raw <- readRDS("01_data/raw/HN24_ALL.rds")

des <- svydesign(
  ids     = ~psu,
  strata  = ~kstrata,
  weights = ~wt_itvex,   # 검진+건강설문
  nest    = TRUE,
  data    = raw
)

# 가중 유병률과 95% CI
svymean(~factor(htn), des, na.rm = TRUE)
svyciprop(~I(htn == 1), des, method = "beta")

# 복합표본 로지스틱
fit <- svyglm(htn ~ age + sex + bmi + smoking,
              design = des, family = quasibinomial())
summary(fit)
confint(fit)

영양 변수를 넣으면 weights = ~wt_tot으로 바꿉니다.

4. 2022–2024를 합칠 때

제9기는 3년간 576개 조사구, 연간 192개입니다(지침서 p.3, p.10). 기수 내 통합의 일반 원칙은 “기존 가중치 × 연도별 조사구 수 비율”입니다(지침서 p.30, 표 7). 9기는 매년 192개로 같으므로:

# 2022, 2023, 2024를 합치는 경우
dat$wt_pool <- dat$wt_itvex * (192 / 576)   # = /3

세 해를 합친 뒤에는 kstrata, psu를 그대로 쓰고, 연도는 보정변수 또는 층으로 검토합니다. 연도를 층에 넣는 것이 항상 정답은 아니므로, 지침서의 통합 예제(표 14–16)를 보고 결정합니다.

주의 — 이 1/3은 지침서의 일반 원칙과 9기 조사구 수에서 유도한 값입니다. 9기 전용 통합 예제가 지침서에 명시되어 있지는 않습니다. 실제 논문용 최종 분석 전에 질병관리청 통계분석 상담 또는 통계 담당자에게 한 번 확인하고, 그 결정을 notes/decision.md에 남기세요.

기수 간 통합은 1/3이 아닙니다. 조사기간 비율을 씁니다. 예를 들어 2007년은 하반기 6개월이라 0.5, 2008–2012년은 각 1, 소계 5.5입니다(지침서 p.31, 표 8). 8기는 코로나19로 2020년이 180개 조사구였지만 조사기간은 1년으로 같아 예외적으로 조사기간 비율을 씁니다(p.30).

5. 실수하기 쉬운 지점

1. wt_exam을 그대로 쓴다 — 2024년 코드북에 없습니다. wt_itvex입니다.

2. 결과 변수만 보고 가중치를 고른다 — 함께 넣는 모든 변수의 부문을 봐야 합니다.

3. 한 논문 안에서 표마다 가중치를 바꾼다 — 가능하면 하나의 분석 가중치로 일관되게. 불가피하면 이유를 방법에 씁니다.

4. 하위집단을 원자료에서 먼저 자른다 — subset(design, ...) 또는 subpop을 씁니다.

5. 결측을 0으로 채운다 — na.rm=TRUE로 제외하고, 결측 수와 처리 방법을 표에 적습니다. SAS는 NOMCAR 옵션을 씁니다.

6. 영양 파일을 개인 단위로 착각한다 — 식품섭취조사(24RC)는 한 사람이 여러 행입니다. 개인 1행 요약 변수를 쓰거나, 집계 후 합칩니다.

7. 2022년 체성분·2024년 폐기능을 다른 해에 적용한다 — wt_bia는 2022년만, wt_pft는 2024년만입니다.

8. 연도 통합을 rbind 후 그냥 분석한다 — 통합가중치를 만들지 않으면 각 해가 인구 규모와 다르게 반영됩니다.

6. 논문 방법에 쓸 문장

“국민건강영양조사 제9기 3차년도(2024) 원시자료를 사용하였다. 복합표본설계를 반영하기 위해 층(kstrata), 집락(psu), 가중치(wt_itvex)를 지정하고 survey 패키지의 svydesign()으로 분석하였다. 건강설문·검진·영양 변수를 함께 포함한 모형에서는 wt_tot을 사용하였다. 하위집단 분석은 설계 객체에서 subset()으로 정의하였다.”
